# Ferramentas WEB

**Ferramentas WEB** é uma Single Page Application (SPA) moderna, ágil que simula o front-end de um site catalogo de ferramentas (elétricas, manuais, EPIs, etc.). O projeto foi construído focado em uma navegação fluida de página única, permitindo que o usuário alterne entre Início, Categorias, Produtos e Cadastro sem qualquer recarregamento da página, foi feito com HTML, CSS e JavaScript.

---

## Tecnologias Utilizadas

* **HTML5**: Estruturação semântica de todo o conteúdo.
* **CSS3**: Estilização visual, uso de variáveis globais, layouts responsivos e efeitos de hover modernos (sombras e transições suaves).
* **JavaScript**: Lógica de roteamento da SPA (ocultar e exibir seções), comportamento do cabeçalho e interações nos botões.

---

## Instruções de Instalação e Execução

Como este projeto é um front-end estático puramente baseado em tecnologias nativas, **não é necessário instalar gerenciadores de pacotes (como npm ou yarn), nem compilar dependências de frameworks**. 

Siga as etapas abaixo para configurar o ambiente e visualizar a aplicação na sua máquina:

### 1. Pré-requisitos
Você precisará apenas de:
* Um **Navegador Web** (Google Chrome, Firefox, Microsoft Edge, Safari).
* Opcional: Um editor de código (como o [Visual Studio Code](https://code.visualstudio.com/)) caso queira visualizar ou editar o código-fonte.

### 2. Configurando o Ambiente Local
Você deve baixar os arquivos do projeto para o seu computador. Caso utilize Git, clone o repositório pelo terminal:

```bash
# Clone o repositório
git clone https://github.com/lopestheus97-sudo/Front_end.git

# Acesse o diretório do projeto
cd Front_end
```
*(Se você fez o download do arquivo .ZIP, basta extraí-lo em uma pasta da sua preferência).*

### 3. Comandos de Inicialização (Como Rodar a Aplicação)

Para visualizar o projeto funcionando, você tem duas opções:

#### Opção A: Abertura Direta
1. Vá até a pasta onde os arquivos do projeto estão salvos.
2. Dê um **duplo clique** no arquivo `index.html`.
3. Ele abrirá automaticamente em seu navegador padrão, 100% funcional.

---

## Estrutura de Pastas e Arquivos

* `index.html` — Estrutura base e todo o conteúdo textual da loja e formulários.
* `style.css` — Todas as regras de design, definição de cores, grid layout e animações.
* `script.js` — Funcionalidades de interação SPA (Single Page Application).
* `imagens/` — Pasta contendo todos os recursos visuais importados nas seções da loja.
