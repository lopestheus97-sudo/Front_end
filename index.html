Cadastrar Novo Produto

Envia os dados em formato JSON através do método POST /api/produtos.

ℹ️ Sobre a Persistência

Ao clicar em cadastrar, a requisição HTTP enviará o corpo em JSON para a rota /api/produtos do back-end Flask.

O registro é gravado com data/hora automática no banco de dados SQLite (database.db) e imediatamente refletido na aba de produtos.

🌐 Serviço Externo Autônomo
🚚

Simulador de Frete e Localização de Entrega

Consome a API pública https://viacep.com.br/ws/{cep}/json/ sem redirecionamento, tratando os dados diretamente na interface.

Formato: 8 dígitos numéricos (com ou sem hífen).

📋 Ficha Técnica da API Externa

  • Nome do Serviço: ViaCEP WebService
  • URL Base: https://viacep.com.br/ws/
  • Licença: Livre, gratuita e de acesso público
  • Autenticação: Não requer cadastro nem chave de API (Tokenless)
  • Método / Rota: GET /{cep}/json/
  • Tratamento na Aplicação: Os dados retornados (logradouro, bairro, localidade, UF, DDD) são processados pelo JavaScript da interface e utilizados para simular prazos e taxas de entrega por região de forma 100% autônoma.
